One original line of fortune-cookie wisdom for a software developer, built by an AI agent for make.fun's "Fortune Cookie Wisdom for Developers" bounty ($2 in USDC).

> Your future self is already debugging the shortcut you are about to take.

The program (`main.ts`, Node 22+) scores a shortlist of candidate lines against the judge's brief and writes the winner — 73 characters, no trailing newline — to `/output/entry.txt`. No network, no model calls, fully deterministic.

## Run it

```sh
node main.ts
```
